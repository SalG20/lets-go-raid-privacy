アカウントとトレーナーの情報

アカウントへのアクセスとレイドの調整を提供するため、お客様のメールアドレス、アカウント識別子、認証・セッションの記録、トレーナープロフィールを処理します。プロフィールには、トレーナー名、トレーナーコード、レベル、チーム、アバターの選択、認証状況、アカウントの設定が含まれます。認証とバックエンドは Supabase が提供しています。Google Sign-In を選択した場合、Google がお客様を認証し、アプリのセッション作成に使用される ID トークンを提供します。登録時のメールアドレス確認では、無効なメールアドレスを検出し不正利用を減らすために ZeroBounce を使用する場合があります。

レイドに必要なトレーナー情報は、お客様が調整を行うトレーナーに表示されます。主催・参加したレイド、準備状況、キャンセル、報告、フィードバック、モデレーションの記録は、サービスの運営と不正利用の防止のために処理されます。

「交流」でフレンドコードの掲載を公開すると、他のアプリユーザーは、掲載に含まれるトレーナー名、フレンドコード、レベル、チーム、アバター、タグ、国、ビビヨンの模様を見ることができ、有効にしている場合はオンライン表示も見ることができます。掲載はいつでも非公開にできます。これらの機能を運営するため、お客様のアカウントに紐づく報酬の活動、ポイント、ゲームの進行状況を保存します。ランキングには、お客様のトレーナー名、順位、ポイントまたはゲームの結果が表示されることがあります。「ランキングに表示する」の設定は変更できます。

レイドのクイックメッセージでは、あらかじめ用意された調整用メッセージを選ぶことができます。Supabase は、選択されたメッセージの識別子、送信者のアカウント識別子、表示名、役割、タイムスタンプ、配信・再送の識別子を処理し、権限のあるレイドルームの参加者にメッセージを送信します。バックエンドは、不正利用や重複メッセージを防ぐため、送信制限と再送に関する情報も保存します。データベースのブロードキャストは、自動削除されるまで Supabase Realtime に保存されます。これらはデバイスのメモリ内だけで処理されるものではなく、配信後すぐに消えることが保証されているものでもありません。クイックメッセージのブロードキャスト（お客様のアカウント識別子と表示名を含みます）は、配信後一定期間、当社のプロバイダーのリアルタイムメッセージログに残ることがあり、お客様がアカウントを削除してもすぐには削除されません。

認証用のスクリーンショットは、文字認識を使用してお客様のデバイス上で処理されます。認証フローでは、スクリーンショットではなく、抽出されたトレーナー情報がバックエンドに送信されます。

メールアドレスでの登録では、ブラウザベースの Cloudflare Turnstile によるセキュリティチェックを使用します。当社のバックエンドはチャレンジトークンを Cloudflare に照会して検証し、メールアドレスを確認のため ZeroBounce に送信します。Turnstile はボットを検出するため、IP アドレス、ブラウザ情報、チャレンジの状況などの技術的なシグナルを処理します。Cloudflare はこれらのシグナルをボット検出の改善にも使用します。詳しくは Turnstile プライバシー補遺をご覧ください。

位置情報

フォアグラウンドでの位置情報の許可は任意です。許可した場合、アプリは緯度と経度（デバイスが許可する場合は正確な座標を含みます）を取得し、逆ジオコーディングによって国、地域、都市に変換することがあります。主催・ボス選択のフローでは、座標とタイムゾーン・位置に関する情報を、レイドの利用可否と参加資格を確認するバックエンド機能に送信します。許可がない場合、位置情報に依存する一部の結果が利用できないことがあります。

おおまかな国・地域・都市の情報と更新日時が、お客様のプロフィールとともに保存される場合があります。すでに位置情報の許可がある場合、アプリは運用上の活動レポートのために国コードも判定します。位置情報へのアクセスに、バックグラウンドでの位置情報の許可は必要ありません。

現在のバックエンドは、正確な座標をレイドの参加資格の確認に使用し、レイドの作成時に正確な座標をレイドの記録に書き込むことはありません。デバイスの位置情報サービスが、国、地域、都市を返すために座標を処理する場合があります。すべてのインフラ処理がメモリ内のみで行われることや、すぐに消去されることは約束しません。サービスログとバックアップには、それぞれ独自の保持の仕組みがあります。バージョン 1.0.7 では、対応するフォアグラウンドの位置情報の許可を与えている場合、Appodeal と BidMachine も広告のためにデバイスのおおよその位置情報または正確な位置情報を収集・共有することがあります。この許可は Android の設定で拒否または取り消すことができます。広告パートナーは、位置情報の許可がなくても IP アドレスからおおよその位置を推定することがあります。AdMob を使用する旧バージョンでは、アプリの広告リクエストのコードで正確な座標を意図的に渡すことはありません。

個体値スキャナー、ライブモード、画面キャプチャ

スクリーンショットのスキャン。個体値スキャナーでスクリーンショットを選択すると、アプリはデバイス上の文字認識を使用してお客様のスマートフォン上でそれを読み取り、ポケモンと、CP、HP、レベル、サイズ、評価などの値を特定します。スクリーンショットとそこから読み取った値は、当社にも広告パートナーにも送信されません。

ライブモード（任意）。ライブモードは Android の画面キャプチャ（MediaProjection）を使用します。開始するたびに Android がお客様に許可を求めます。最近の Android バージョンでは、1 つのアプリ（ポケモンGOのみを推奨します）または画面全体を共有できます。ライブモードがオンの間は、次のようになります。

  • 停止ボタン付きの通知が表示されます。
  • アプリは共有された画面を継続的に受け取り、最新の画像 1 枚だけをメモリに保持します。
  • 新しく安定した画面が表示されたとき（自動スキャン）と、フローティングの目のボタンをタップしたときに、共有された画面を自動的に解析します。画面全体を共有している場合、お客様が開いた他のアプリの画面も、スマートフォン上で短時間解析されることがあります。ポケモンの画面ではないものはすべて破棄されます。
  • 画像はお客様のスマートフォン上でデコード・解析されます。アップロード、動画としての録画、当社や第三者への送信は行われません。
  • 一時的な画像はアプリの非公開ストレージに保存され、新しい画面が解析されるたびに置き換えられ、ライブモードの停止時に削除されます。
  • フローティングボタンと結果は、Android の「他のアプリの上に表示」の許可を使用して他のアプリの上に表示されます。他のアプリの上に広告が表示されることはありません。

ライブモードは、通知、フローティングボタンのメニュー、ライブモードの画面、または Android の画面共有インジケーターから停止できます。重ねて表示、通知、画面キャプチャの各許可は、Android の設定でいつでも取り消すことができます。

文字認識。文字認識には Google Play 開発者サービスを通じて提供される Google ML Kit を使用し、お客様のデバイス上で実行されます。Google の ML Kit データ開示に記載されているとおり、Google はデバイスとアプリの情報、パフォーマンス指標、エラーコードなどの技術情報を受け取ることがあります。画像の内容は送信されません。

保存したポケモン。スキャンしたポケモンを保存すると、その値、スクリーンショットの縮小コピー、サムネイルが、当社のサーバーではなくお客様のスマートフォン上のアプリの非公開ストレージに保存され、お客様がスキャンを削除するかアプリをアンインストールするまで保持されます。デバイスで Android のバックアップが有効になっている場合、Android がこのアプリデータをお客様の Google アカウントへのデバイスのバックアップに含めることがあります。

画像の共有、コピー、保存。お客様が選択した場合に限り、アプリは結果パネルの画像を作成し、Android の共有シートで共有したり、クリップボードにコピーしたり、スマートフォンの Pictures/Let's Go Raid フォルダに保存したりできます。このフォルダの画像は、写真へのアクセス権を持つ他のアプリから見ることができます。アプリはクリップボードに書き込みますが、クリップボードを読み取ることはありません。

ポケモンの画像。ポケモンの画像は、必要に応じて GitHub 上でホストされている公開画像リポジトリ（raw.githubusercontent.com）から読み込まれます。これらのリクエストにアカウント情報は含まれませんが、ホストはお客様の IP アドレスやリクエストされた画像などの標準的な技術データを受け取ります。

オンボーディングの質問とタイムゾーン

アカウントの作成後（既存のアカウントの場合は 1 回）、アプリが「どこでこのアプリを知りましたか？」と尋ねることがあります。回答は任意で、スキップすることもできます。選択肢は Instagram、Facebook、TikTok、YouTube、友だち・家族、App Store、その他です。「その他」を選んだ場合、短い説明（80 文字まで）を任意で入力できます。選択した項目、入力したテキスト、質問に回答したかスキップしたかを、お客様のアカウントに紐づけて保存します。この情報は、このアプリがどのように知られているかを把握し、マーケティングを改善するために使用します。他のトレーナーには表示されず、当社のアプリがこの情報を広告プロバイダーに送信することはありません。

アプリは、お客様のデバイスに設定されているタイムゾーン（例: Europe/Madrid）を読み取ります。初期の候補として、そのタイムゾーンが属する国と、デバイスの言語・地域設定の地域を使用する場合もあります。タイムゾーンの検出はデバイスの設定のみを使用し、GPS は使用せず、位置情報の許可も求めません。オンボーディング中に、オフラインの都市・国のリストを任意で検索して選ぶことができます。検索はお客様のデバイス上で行われます。当社は、お客様のタイムゾーンを IANA タイムゾーン識別子として保存するほか、お客様が選択した国または提案された国、都市を選んだ場合はその都市と地域、そしてお客様が最後にタイムゾーンを確認した日時を保存します。「設定 > タイムゾーン」で、デバイスに現在設定されているタイムゾーンに更新できます。レイドの主催に使用するタイムゾーンの変更は、24 時間に 1 回可能です。

この情報は、設定画面にタイムゾーンの設定を表示するため、および、現地時間または地域ごとに出現するレイドボスのうちお客様が主催できるものを確認するために使用します（これらの確認には、お客様が確認したタイムゾーンとサーバー時刻を使用します）。デバイスのタイムゾーンやお客様が選んだ都市は検証されず、お客様の実際の所在地の証明としては扱われません。この情報は他のトレーナーには表示されず、当社のアプリがこの情報を広告プロバイダーに送信することはありません。

これらの回答は当社のバックエンド（Supabase）に保存され、アプリがオフラインでも表示できるようにコピーがお客様のデバイスに保存されます。アクセスできるのは、アプリを通じたお客様ご本人とアプリの運営者のみです。お客様のアカウントが存在する間は保持され、アカウントとともに削除されます（設定 > アカウントを削除）。アクセスや訂正をご希望の場合は当社までご連絡ください。

広告とプライバシーの選択

バージョン 1.0.7 の広告 SDK には、Appodeal、BidMachine、Bidon、AppLovin、Mintegral、Unity Ads、Liftoff Monetize（Vungle）、Meta Audience Network、Pangle が含まれます。Sentry は SDK のクラッシュレポートをサポートしています。Appodeal は、広告とアナリティクスのために、広告の操作、広告 ID その他の識別子、デバイス・ネットワークの技術情報、診断情報、その他のアプリのパフォーマンスデータを収集します。メディエーション広告 SDK も、広告配信、効果測定、アナリティクス、セキュリティ、不正防止のためにこれらのデータを処理することがあります。取り扱いはプロバイダーによって異なります。データは広告・効果測定パートナーと共有されることがあります。許可と同意の選択は収集に影響します。パーソナライズド広告を拒否しても、すべての技術データの収集が止まるとは限りません。リワード広告では、報酬の確認と不正利用の防止のため、当社のアプリが不透明な報酬識別子を Appodeal に渡します。当社のバックエンドはこの識別子をお客様のアカウントに紐づけます。これは匿名ではなく仮名の識別子です。お客様の生のアカウント ID、メールアドレス、トレーナー名ではありません。アプリが購入イベントを Appodeal に直接送信することはありません。ただし、同梱されている他の SDK による収集を排除するものではありません。Unity Ads は、アプリの機能のための個人識別子の収集・共有、および広告とアナリティクスのための購入履歴の収集・共有について文書で示しています。Google Play と RevenueCat は、以下に説明するとおり購入を処理します。

バージョン 1.0.7 では、バナー広告に Appodeal のメディエーションを、機能を一時的に利用するための任意のリワード広告を使用しています。リワード広告でプレミアムや永久の広告削除が付与されることはありません。広告なしのアクセスでは、バナーの表示枠が非表示になります。インタースティシャル広告やアプリ起動時広告の形式は実装していません。インストール済みの旧バージョンでは、バナーを無効にしたうえで、リワード広告に Google AdMob を使用している場合があります。

AdMob を使用するインストール済みの旧バージョンでは、Google Mobile Ads SDK が、広告、効果測定、アナリティクス、セキュリティ、不正防止のために、IP アドレス、IP から推定されるおおよその位置、広告 ID・アプリセット ID その他のデバイス識別子、アプリ・広告の操作、診断情報を処理します。Google とその広告パートナーは、それぞれのポリシーに基づいてこれらの情報を処理します。パーソナライズされていない広告でも、識別子、ストレージ、効果測定が関わることがあります。

バージョン 1.0.7 では、必要な場合にプライバシーの選択を取得するため、SDK の初期化時に Appodeal Stack Consent Manager を使用します。AdMob を使用するインストール済みの旧バージョンでは、Google User Messaging Platform（UMP）を使用します。必要な場合、「設定」の「広告のプライバシー設定」からプライバシーフォームを再表示できます。利用できるかどうかは、お客様の地域と同意プラットフォームの要件によって異なります。デバイスの設定でも広告 ID を管理できます。任意のリワード広告を断っても、アカウントが削除されたり、通常のレイド調整ができなくなったりすることはありません。

購入

月額プレミアム（monthly_premium）と、別売りの広告削除（remove_ads）は、Google Play Billing を通じて購入できます。RevenueCat は、確認、復元、購入分析のために、アカウント・顧客の識別子、購入履歴、サブスクリプションの状態、利用権を処理します。当社のバックエンドは、アクセス状態を最新に保つために請求イベントを受け取ります。当社が支払いカードの完全な情報を受け取ることはありません。サブスクリプションと返金は Google Play で管理されます。アプリのアカウントを削除しても、それだけで Google Play のサブスクリプションが解約されるわけではありません。

通知と運用データ

通知を有効にした場合、Expo と Google/Firebase の通知サービスが、プッシュトークン、デバイス・インストールの識別子、プラットフォーム情報、配信データを処理します。当社のバックエンドは登録情報と設定情報を保存し、レイドやサービスに関する通知を送信します。通知は「設定」または Android の通知設定で無効にできます。

信頼性の確保、アナリティクス、サポート、不正利用の防止のために、アプリ・ビルドのバージョン、オペレーティングシステム、デバイスのモデル、セッション識別子、画面・活動のイベント、エラーの概要を処理します。活動レポートはお客様のアプリのアカウントに紐づけられます。広告 SDK の診断情報は、当社の運用レポートとは別のものです。

デバイスの許可。使用する機能に応じて、アプリは次の許可を求めることがあります: 通知、フォアグラウンドの位置情報（主催の参加資格とおおまかな国・地域）、古い Android バージョンでの写真へのアクセス（スクリーンショットの選択）、画面キャプチャと他のアプリの上への表示（ライブモード）。いずれも任意で、Android の設定で取り消すことができます。取り消した場合、関連する機能は動作しなくなります。

プロバイダーと開示
