帳戶與訓練家資訊

為提供帳戶存取及團體戰協調功能，我們會處理您的電子郵件地址、帳戶識別碼、驗證／工作階段紀錄及訓練家個人檔案。您的個人檔案包括訓練家名稱、訓練家代碼、等級、隊伍、虛擬形象選擇、驗證狀態及帳戶偏好設定。Supabase 提供身分驗證及我們的後端服務。若您選擇 Google Sign-In，Google 會驗證您的身分，並提供用於建立應用程式工作階段的身分權杖。註冊時的電子郵件檢查可能使用 ZeroBounce 偵測無效的電子郵件地址並減少濫用。

團體戰所需的訓練家資訊，會顯示給與您協調的訓練家。您主辦／加入的團體戰、準備狀態、取消、檢舉、意見回饋及管理紀錄，會為了營運服務及防止濫用而受到處理。

若您在「社群」中公開好友代碼刊登，其他應用程式使用者可以看到您刊登內容中包含的訓練家名稱、好友代碼、等級、隊伍、虛擬形象、標籤、國家及彩粉蝶花紋；若您啟用，還可看到上線狀態標示。您可以取消公開您的刊登。為營運這些功能，我們會儲存與您帳戶連結的獎勵活動、點數及遊戲進度。排行榜可能顯示您的訓練家名稱、排名及點數或遊戲成績；您可以變更「在排行榜顯示我」偏好設定。

團體戰快速訊息可讓您選擇預先定義的協調訊息。Supabase 會處理所選訊息的識別碼、傳送者帳戶識別碼、顯示名稱、角色、時間戳記及傳送／重試識別碼，以便將訊息傳送給已獲授權的團體戰房間參與者。後端也會儲存傳送頻率限制及重試資訊，以防止濫用及重複訊息。資料庫廣播在自動清除前會儲存於 Supabase Realtime；這些廣播並非僅在裝置記憶體中處理，也不保證在傳送後立即消失。快速訊息廣播（包括您的帳戶識別碼及顯示名稱）在傳送後可能會在我們供應商的即時訊息紀錄中保留一段有限期間，且不會在您刪除帳戶時立即移除。

驗證用螢幕截圖會使用文字辨識在您的裝置上處理。驗證流程會將擷取出的訓練家資訊（而非螢幕截圖本身）傳送至我們的後端。

電子郵件註冊會使用以瀏覽器為基礎的 Cloudflare Turnstile 安全性檢查。我們的後端會透過 Cloudflare 驗證挑戰權杖，並將電子郵件地址傳送至 ZeroBounce 進行驗證。Turnstile 會處理 IP 位址、瀏覽器資訊及挑戰情境等技術訊號以偵測機器人；Cloudflare 也會使用這些訊號改善其機器人偵測。請參閱其 Turnstile 隱私權附錄。

位置

前景位置權限為選擇性。若您授予此權限，本應用程式可取得經緯度（在您的裝置允許時包括精確座標），並以反向地理編碼轉換為國家、地區及城市。主辦／頭目選擇流程會將座標及時區／位置資訊傳送至後端功能，以檢查團體戰的可用性及參加資格。若未授予權限，部分依賴位置的結果可能無法使用。

概略的國家／地區／城市資訊及更新時間可能會與您的個人檔案一併儲存。若已有位置權限，本應用程式也會判定國家代碼以用於營運活動報告。存取位置不需要背景位置權限。

我們目前的後端會使用精確座標檢查團體戰參加資格，且在建立團體戰時不會將精確座標寫入團體戰紀錄。裝置的定位服務可能會處理座標以傳回國家、地區或城市。我們不承諾所有基礎架構處理皆僅在記憶體中進行或會立即清除。服務紀錄及備份有其各自的保留方式。在 1.0.7 版中，若您已授予相應的前景位置權限，Appodeal 與 BidMachine 也可能為廣告目的蒐集及分享裝置的概略或精確位置。您可以在 Android 設定中拒絕或撤銷此權限。即使沒有位置權限，廣告合作夥伴仍可能從 IP 位址推斷概略位置。使用 AdMob 的舊版本不會在應用程式的廣告請求程式碼中刻意傳遞精確座標。

個體值掃描器、即時模式與螢幕擷取

螢幕截圖掃描。當您在個體值掃描器中選擇螢幕截圖時，本應用程式會在您的手機上使用裝置端文字辨識讀取該截圖，以辨識寶可夢及 CP、HP、等級、尺寸與評價等數值。螢幕截圖及從中讀取的數值不會傳送給我們或廣告合作夥伴。

即時模式（選擇性）。即時模式使用 Android 螢幕擷取（MediaProjection）。每次您啟動時，Android 都會徵求您的許可；在較新的 Android 版本中，您可以分享單一應用程式（我們建議僅分享 Pokémon GO）或整個螢幕。即時模式開啟期間：

  • 會顯示附有「停止」按鈕的通知；
  • 本應用程式會持續接收所分享的畫面，且僅在記憶體中保留最新的一張影像；
  • 當出現新的穩定畫面時（自動掃描）以及您點選浮動眼睛按鈕時，本應用程式會自動分析所分享的畫面。若您分享整個螢幕，您開啟的其他應用程式畫面也可能在您的手機上被短暫分析；任何非寶可夢畫面的內容都會被捨棄；
  • 影像會在您的手機上解碼及分析，不會被上傳、錄製成影片，或傳送給我們或第三方；
  • 暫存影像會儲存在本應用程式的私人儲存空間中，在分析新畫面時被取代，並於即時模式停止時刪除；
  • 浮動按鈕及結果會透過 Android 的「顯示在其他應用程式上層」權限顯示於其他應用程式上層。不會在其他應用程式上層顯示廣告。

您可以從通知、浮動按鈕選單、即時模式畫面或 Android 的螢幕分享指示器停止即時模式。您可以隨時在 Android 設定中撤回疊加顯示、通知或螢幕擷取權限。

文字辨識。文字辨識使用透過 Google Play 服務提供的 Google ML Kit，並在您的裝置上執行。如 Google 的 ML Kit 資料揭露所述，Google 可能會收到裝置及應用程式資訊、效能指標及錯誤代碼等技術資訊；影像內容不會被傳送。

已儲存的寶可夢。若您儲存已掃描的寶可夢，其數值、縮小後的螢幕截圖副本及縮圖會儲存在您手機上本應用程式的私人儲存空間中（而非我們的伺服器上），直到您刪除該掃描或解除安裝本應用程式為止。若您的裝置已啟用 Android 備份，Android 可能會將此應用程式資料納入備份至您 Google 帳戶的裝置備份中。

分享、複製及儲存影像。僅在您選擇時，本應用程式才會建立結果面板的影像，並可透過 Android 分享選單分享、複製到剪貼簿，或儲存至您手機的 Pictures/Let's Go Raid 資料夾；具有相片存取權的其他應用程式可以看到該資料夾中的影像。本應用程式會寫入剪貼簿，但絕不會讀取剪貼簿。

寶可夢圖片。寶可夢圖片會在需要時從託管於 GitHub 的公開圖片儲存庫（raw.githubusercontent.com）載入。這些請求不包含帳戶資訊，但主機會收到標準技術資料，例如您的 IP 位址及所請求的圖片。

新手引導問題與時區

在您建立帳戶後（既有帳戶則為一次），本應用程式可能會詢問「你是從哪裡得知我們的？」。回答為選擇性，您可以略過。選項為 Instagram、Facebook、TikTok、YouTube、朋友或家人、App Store 及其他。若您選擇「其他」，您可以自願輸入簡短說明（最多 80 個字元）。我們會儲存您所選的選項、您輸入的任何文字，以及您是否已回答或略過該問題，並與您的帳戶連結。我們使用此資訊了解使用者如何發現本應用程式，並改善我們的行銷。此資訊不會顯示給其他訓練家，我們的應用程式也不會將其傳送給廣告供應商。

本應用程式會讀取您裝置上設定的時區（例如 Europe/Madrid）。作為初始建議，本應用程式也可能使用該時區所屬的國家，以及您裝置語言／地區設定中的地區。時區偵測僅使用裝置設定；不使用 GPS，也不會要求位置權限。在新手引導期間，您可以選擇搜尋離線的城市及國家清單並從中選擇；搜尋在您的裝置上執行。我們會以 IANA 時區識別碼儲存您的時區，並儲存您所選擇或系統建議的國家、您選擇城市時的城市及地區，以及您上次確認時區的時間。在「設定 > 時區」中，您可以將其更新為您裝置目前設定的時區；用於主辦團體戰的時區每 24 小時可變更一次。

我們使用此資訊在您的設定中顯示您的時區偏好，並檢查有哪些依當地時間或地區開放的團體戰頭目可由您主辦（這些檢查使用您已確認的時區及伺服器時間）。裝置時區或您選擇的城市不會經過驗證，也不會被視為您實際所在位置的證明。此資訊不會顯示給其他訓練家，我們的應用程式也不會將其傳送給廣告供應商。

這些回答會儲存在我們的後端（Supabase），並在您的裝置上保留一份副本，讓本應用程式可以離線顯示。只有您本人（透過本應用程式）及本應用程式的營運者可以存取這些資訊。這些資訊會在您的帳戶存在期間保留，並與您的帳戶一併刪除（設定 > 刪除帳戶）。您可以聯絡我們以查閱或更正這些資訊。

廣告與隱私權選擇

1.0.7 版的廣告 SDK 包括 Appodeal、BidMachine、Bidon、AppLovin、Mintegral、Unity Ads、Liftoff Monetize（Vungle）、Meta Audience Network 及 Pangle；Sentry 支援 SDK 當機回報。Appodeal 會為廣告及分析目的蒐集廣告互動、廣告識別碼及其他識別碼、裝置／網路技術資訊、診斷資訊及其他應用程式效能資料。中介廣告 SDK 也可能為廣告投放、成效評估、分析、安全性及詐欺防範目的處理這些資料；各供應商的做法不盡相同。資料可能會與廣告及成效評估合作夥伴分享。權限及同意選擇會影響蒐集；拒絕個人化廣告不必然會停止所有技術資料的蒐集。對於獎勵廣告，我們的應用程式會將不透明的獎勵識別碼傳遞給 Appodeal，以驗證獎勵並協助防止濫用。我們的後端會將此識別碼與您的帳戶連結；它屬於假名化資料，而非匿名資料。它並非您的原始帳戶 ID、電子郵件地址或訓練家名稱。本應用程式不會直接將購買事件傳送給 Appodeal。但這並不排除其他隨附 SDK 的蒐集：Unity Ads 的文件說明其會為應用程式功能蒐集及分享個人識別碼，並為廣告及分析蒐集及分享購買紀錄。Google Play 與 RevenueCat 會依下文所述處理購買。

1.0.7 版使用 Appodeal 中介服務提供橫幅廣告，以及用於暫時使用功能的選擇性獎勵廣告。獎勵廣告不會授予 Premium 或永久刪除廣告。無廣告權限會隱藏橫幅廣告版位。本應用程式未實作插頁式或應用程式開啟廣告格式。已安裝的舊版本可能使用 Google AdMob 提供獎勵廣告，並停用橫幅廣告。

在使用 AdMob 的已安裝舊版本中，Google Mobile Ads SDK 會為廣告、成效評估、分析、安全性及詐欺防範目的，處理 IP 位址、從 IP 推斷的概略位置、廣告／應用程式組 ID 或其他裝置識別碼、應用程式／廣告互動及診斷資訊。Google 及其廣告合作夥伴會依其政策處理這些資訊。非個人化廣告仍可能涉及識別碼、儲存及成效評估。

1.0.7 版會在 SDK 初始化期間使用 Appodeal Stack Consent Manager，以在必要時取得隱私權選擇。使用 AdMob 的已安裝舊版本則使用 Google User Messaging Platform（UMP）。在必要時，「設定」中的「廣告隱私選項」可重新開啟隱私權表單。是否提供此功能取決於您所在的地區及同意平台的要求。您也可以透過裝置設定管理廣告識別碼。拒絕選擇性的獎勵廣告不會刪除您的帳戶，也不會妨礙一般的團體戰協調。

購買

每月 Premium（monthly_premium）及另行購買的刪除廣告（remove_ads）可透過 Google Play Billing 購買。RevenueCat 會為驗證、恢復及購買分析目的，處理帳戶／客戶識別碼、購買紀錄、訂閱狀態及權益。我們的後端會接收帳單事件，以維持存取權限為最新狀態。我們不會收到完整的付款卡資料。訂閱及退款透過 Google Play 管理。刪除應用程式帳戶本身並不會取消 Google Play 訂閱。

通知與營運資料

若您啟用通知，Expo 及 Google/Firebase 通知服務會處理推播權杖、裝置／安裝識別碼、平台資訊及傳送資料。我們的後端會儲存註冊及偏好設定資訊，並傳送團體戰／服務通知。您可以在「設定」或 Android 的通知設定中停用通知。

為確保可靠性、進行分析、提供支援及防止濫用，我們會處理應用程式／建置版本、作業系統、裝置型號、工作階段識別碼、畫面／活動事件及錯誤摘要。活動報告會與您的應用程式帳戶連結。廣告 SDK 的診斷資訊與我們的營運報告是分開的。

裝置權限。視您使用的功能而定，本應用程式可能會要求以下權限：通知；前景位置（主辦資格及概略國家／地區）；在較舊 Android 版本上的相片存取權（選擇螢幕截圖）；螢幕擷取及顯示在其他應用程式上層（即時模式）。每項權限皆為選擇性，並可在 Android 設定中撤回；撤回後，相關功能將停止運作。

供應商與揭露

廣告供應商資訊：Appodeal、BidMachine、Bidon、AppLovin、Mintegral、Unity、Liftoff、Meta、Pangle 及 Sentry。
